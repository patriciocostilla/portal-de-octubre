# Portal de Octubre ✧

Cuenta regresiva al próximo **29 de octubre**, con estética de juego de rol en tonos rosa y pequeñas misiones al tirar un d20.

Sitio estático en HTML, CSS y JavaScript, sin dependencias de compilación. Usa la hora local del visitante. El 29 de octubre muestra el portal abierto durante todo el día; el 30 empieza a contar hacia el año siguiente. Las fuentes de Google tienen alternativas locales si no hay conexión.

## Desarrollo

Desde esta carpeta, ejecutar `python3 -m http.server 8080` y abrir http://localhost:8080.

## Publicación

GitHub Pages sirve la raíz de la rama `main`. Todos los recursos usan rutas relativas para funcionar en una página de proyecto.
